# Security policy

The app stores everything on the device and has no network code, but if you find a security problem (for example a crafted `.sijil` file that crashes or corrupts the app), please report it privately:

1. Open the **Security** tab of this repository.
2. Choose **Report a vulnerability** and describe the problem and the steps to reproduce it.

Please do not open a public issue for security problems, and never include real account numbers or names. Only the latest release receives fixes.
